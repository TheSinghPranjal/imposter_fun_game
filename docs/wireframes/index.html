Open decisions

Nothing is open. Everything below was decided.

Settled

  • App ID: com.lazybearclub.find_the_imposter; desktop and web folders removed.
  • Android minimum: API 24, required by Flutter 3.41 and the AdMob plugin.
  • Hold gesture: Raw touch events, so the 800 ms starts on contact.
  • App-switcher protection: Native FLAG_SECURE on Android and a cover view on iOS.
  • Proposed wording: Approved as drawn, including “Player 3 of 6” on Pass phone.
  • Accepted defaults: Names kept in memory only. Existing duplicates stay if the setting is turned off. A missed ad slot waits for the next multiple of 4. WoodSign is a 9-slice image. Round options live on Configuration.
